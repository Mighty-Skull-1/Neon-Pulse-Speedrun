**Neon Pulse** is a high-octane, neon-drenched precision speedrun platformer built entirely in pure vanilla JavaScript and HTML5 Canvas. Experience fluid sub-frame acrobatic physics, a collective 3-ability exosuit matrix, 20 curated campaign stages spanning two dimensions, daily seeded challenges, an infinite procedural marathon mode, customizable exosuits & particle trails, and real-time 1v1 WebRTC multiplayer racing.

Play online now on **[GitHub Pages](https://mighty-skull-1.github.io/Neon-Pulse-Speedrun/)**!

### 🖥️ Fullscreen & Keyboard Lock Integration
- **Keyboard Lock API**: In Fullscreen mode, the game locks `[ESC]` via `navigator.keyboard.lock(['Escape'])`. Pressing **`[ESC]`** pauses smoothly **without dropping out of Fullscreen** or resizing the window!
- **Dedicated Hotkeys**: Toggle Fullscreen with **`[G]`** or the header / pause menu buttons. Pause/resume with **`[ESC]`** or **`[P]`**.

## 🚀 Quick Start / Local Play

Neon Pulse requires **zero build steps** and **zero external npm dependencies**. It runs natively in any modern web browser.

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Mighty-Skull-1/Neon-Pulse-Speedrun.git
   cd Neon-Pulse-Speedrun
   ```
2. **Launch a local web server** (required for WebRTC networking and AudioContext):
   ```bash
   npx serve .
   # or
   python -m http.server 8080
   ```
3. Navigate to `http://localhost:8080` in your browser and start running!

## 🧪 Architecture & Tech Stack

- **Graphics**: Hardware-accelerated HTML5 2D Canvas with sub-frame render state interpolation (`renderX`, `renderY`) and adaptive DPR scaling.
- **Physics**: Fixed-timestep Euler integrator (120Hz) with 120ms coyote time, 160ms jump buffering, and +15% slide-hop velocity chaining.
- **Audio Engine**: Pure Web Audio API master bus architecture with independent `musicGainNode` and `sfxGainNode` routing.
- **Networking**: WebRTC DataChannels via PeerJS for peer-to-peer telemetry and sub-millisecond racing inputs.
- **UI & Styling**: Tailwind CSS CDN + custom neon glassmorphic CSS backdrops and cyber glow filters.
- **Storage**: Clean `localStorage` schema with versioned migrations, progress resets, and setting persistence.
